# Página romántica ❤️

## Archivos
- `index.html`
- `style.css`
- `script.js`
- `sisi.png`

## Para probarla en Visual Studio Code
Abre la carpeta y abre `index.html` con Live Server, o simplemente abre el archivo en el navegador.

## Para GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube los cuatro archivos manteniendo `sisi.png` en la misma carpeta que `index.html`.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub genere la página.

La canción está integrada mediante el video oficial de YouTube de “Tu Cariñito” de Edén Muñoz.
